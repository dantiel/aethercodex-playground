## 📱 Mobile Support

- **Submarine**: Querformat — linker Joystick (Bewegung), rechter Joystick (Zielen), Feuer- & Waffen-Buttons
- **Rocket Car**: Hochformat — tippe links/rechts zum Lenken, Mitte für Gas

## 🔧 Development

All games are self-contained HTML files. Open any `.html` file directly in a browser — no build step required.
